Add `NumberInput` — a number field with custom themed increment/decrement steppers replacing the native browser spinners. Hides the native `::-webkit` and Firefox spinners, renders stacked chevron buttons that respect `min`/`max`/`step` via the input's `stepUp`/`stepDown`, and fires `onChange` for both controlled and uncontrolled usage. Supports `sm`/`md`/`lg` sizes, form-field context (`disabled`/`invalid`/`required`/`aria-describedby` wiring with matching disabled, focus, and invalid border treatment), and `incrementLabel`/`decrementLabel`. Also exports `ChevronUpIcon` and `ChevronDownIcon`.
